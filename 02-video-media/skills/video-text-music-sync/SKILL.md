# 视频配字与音乐卡点

1. 读工程和媒体流，确认实际时长、分辨率、音轨和基于有理数的帧率。明确剪辑可调整范围，将已经批准的镜头与原声关系视为输入。
2. 给每条配字记录来源、时间线整数帧、文案、样式、声音或动作依据和待复核项。歌词时间使用发音起点，文字重音和节拍分别记录。
3. 先找文字存续期间的留白，沿人物运动轨迹检查遮挡。维护可编辑文字、前景遮罩、背景、音乐和原声轨。空间跟踪与人物穿字逐段检查。
4. 使用 [时间表与辅助脚本](timing.md) 记录候选时间和生成基础合成脚本。把自动检测、人工或可靠工具复核、最终采用分别记录。
5. 输出连续预览，核对文字驻留、遮罩边缘、镜头前后音画关系、首尾同步、分辨率和精确帧率。交付工程、时间表和成片或审稿预览。
