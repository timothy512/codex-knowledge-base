# 配音视频工程协作

1. 分开保存原稿、配音读法稿和屏幕字幕。型号、单位、数字和中英混读用显式映射表记录。
2. 用批准的声音生成配音，保存最终音轨。通过语音识别回读音频辅助找错。更换配音后重新对齐相应段落。
3. 按实际音轨做字词级对齐。长音频按真实语音断点分段，拼接时把局部时间加回段落绝对偏移。对齐稿与读法稿内容要对应。
4. 依语义、时长和屏幕阅读量做字幕分段。配音、字幕及镜头节奏分别检查，必要时回到话术或选镜修改。
5. 交付保留复用所需的时间表、字幕、配音和工程文件。从最终成片检查开头、结尾、难读词、衔接和声音峰值。
