# 品牌、包装与印前项目经验

## 品牌视觉系统与跨产品延展

多条产品线需要共享一个品牌识别，同时保留货架和小标签上的品类差异。

**做法** 先确定标志组合、主文字和背景，再用可控的辅色、网格和辅助图形区分系列。把规则分别落到主标、横标、纯平版和小尺寸标签。

**验收** 在纸白底、实物浅底与线上缩略图上复核识别度。用正反侧和开盒结构验证规则能否延续。

## 八色模型颜料标签与条码

同版式下配套多色商品，需要逐 SKU 对应颜色和商品码。

**做法** 建立 SKU、色名、色块、净含量、原始 GTIN 的映射表。校验后生成独立条码矢量，模板批量排版，再导出单张和合订稿。

**验收** 逐色核对颜色与条码归属，检查最终 PDF 的实际尺寸、静区、印刷文字与小图可读性。

## 抽拉与翻盖套盒的刀模和图稿

同一套产品尝试不同结构，包装套版和结构验证需要可独立交接。

**做法** 分离外盒、内托、开窗或翻盖结构。先核对折翼、插舌与内托的装配余量，再让底色实际越过裁切线，逐边检查旧蒙版和白色折翼。

**验收** 交付刀线、印刷稿和审稿图，使用实际刀模尺寸核查。开合、内托取用和纸厚配合在打样记录。

## 短标签的信息架构

多个颜料品类需要共享狭窄瓶贴模板，型号、规格、警示和商品码同时可读。

**做法** 固定品牌和品类区域。净含量、适用场景及标准字段用数据替换。商品码按扫描区留白，图形辅助从边缘和小尺寸优先审视。

**验收** 做成品比例预览，逐款检查模板继承、任何默认字段、跨款错码和小字分辨率。

## 周边物料的多 Agent 生图协作

周边物料设计需要先定概念方向，再批量出图并逐轮收敛细节。

**做法** 先读既有设计文档锁定图形元素、配色和使用场景。主 Agent 负责设计概念和生图提示词，子 Agent 批量出图，主 Agent 逐图给出保留、调整或重画的具体意见，再按反馈迭代。

**验收** 对照设计文档核对元素与配色，检查概念图到成图的一致性；每轮修改意见能对应到具体画面区域，避免只给笼统评价。
