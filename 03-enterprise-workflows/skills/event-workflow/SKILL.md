# 任务事件与人工审批

1. 从一个触发器和一个可验证结果开始。定义事件字段、业务周期、去重键、处理时限、负责人和输出。
2. 先用授权来源和虚构样本本地回放。记录事件接收、处理、生成草稿、批准和交付的独立状态。
3. 用唯一键或锁合并同周期并发重跑。失败恢复时先读取已有的落盘或发布记录，再决定补跑哪一步。
4. 涉及外发、帐号授权或需要账号持有者接管的操作保留明确的人工节点。记录待办和恢复条件。
5. 验证空结果、重复事件、部分成功、权限缺失、外部失败和重启恢复。日志只记录脱敏索引、状态和错误摘要。
